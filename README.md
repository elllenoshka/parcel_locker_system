# Parcel Locker System

University project for two courses:
- Web Interactions
- Distributed and Parallel Computing (DPC)

## Topic
C11 — Parcel Lockers (Поштомати)

The system is designed for parcel locker reservations, parcel drop-offs and pickups, notifications, and distributed data processing.

## Technologies
- Java
- Spring Boot
- PostgreSQL
- Docker Compose
- Kafka
- Ray and Apache Spark
- etcd

## Project Structure
- `web/` — Web Interactions application
- `dpc/` — Distributed and Parallel Computing application
- `compose.yaml` — shared services configuration (planned)

## Team
4 students working on one shared project.

## Status
Initial project setup. Implementation is in progress.
